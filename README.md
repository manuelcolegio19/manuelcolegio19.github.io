## 🚀 Descripción del Proyecto

**ShoesErCañas** es una aplicación web *Single-File* (`index.html`) inspirada en las grandes tiendas de *resell* y cultura urbana actuales. Está centrada exclusivamente en el mercado de las **zapatillas exclusivas (Sneakers)**, ofreciendo desde pares de rotación diaria (*Adidas Samba, Handball Spezial, Asics Gel-Kayano 14*) hasta los *Holy Grails* más cotizados (*Jordan 1 Low x Travis Scott, Air Jordan 4 Bred, Nike Air Max Plus TN*).

El proyecto combina un diseño **Negro Mate y Rojo Carmesí** de alto impacto visual con una experiencia de usuario (UX) rápida, interactiva y sin necesidad de recargar la página.

---

## ✨ Características Principales

### 🎨 Diseño & Animaciones (UI/UX)
* **Estética "Bred" (Black & Red):** Paleta de colores oscura (`#070709` y `#111116`) combinada con acentos en rojo neón (`#e11d48` / `#ff1e42`) y sombras iluminadas (*glow effects*).
* **Efecto 3D Tilt Interactivo:** La zapatilla principal del *Hero* reacciona en 3D al movimiento del ratón mediante perspectiva CSS y JavaScript.
* **Marquesinas Infinitas (*Tickers*):** Barras animadas en bucle continuo para anuncios de envíos, marcas y *footer*, que se pausan al pasar el cursor por encima.
* **Scroll Reveal:** Las secciones de la web aparecen suavemente a medida que el usuario baja por la página gracias a la API `IntersectionObserver`.
* **Mega-Menú Desplegable:** Navegación superior categorizada por siluetas y marcas (*Air Jordan, Nike, Adidas, Asics & New Balance*).

### 🛒 Funcionalidades E-Commerce (JavaScript Dinámico)
* **Sincronización de Imágenes Reales (API Rest):** Conexión automática con la API de *Wikimedia Commons* para garantizar que cada modelo de zapatilla muestre su fotografía real y exacta, contando además con URLs de respaldo verificadas.
* **Filtrado Instantáneo por Marcas y Ofertas:** Filtra el catálogo sin recargar la página entre *Air Jordan, Nike, Adidas, Asics, New Balance* o *Solo Rebajas (-20%)*.
* **Selector Rápido de Tallas (*Quick-Add*):** Al pasar el ratón sobre cualquier zapatilla, emerge un panel inferior que permite añadir directamente la talla europea (`EU 37` a `EU 45`) al carrito, bloqueando automáticamente las tallas agotadas.
* **Modal de Vista Rápida (*Quick View*):** Ventana emergente con foto ampliada, etiquetas de estado (*Grail, Bestseller, Steal*), guía de tallas interactiva y verificación *Legit Check*.
* **Buscador en Tiempo Real:** Modal de búsqueda instantánea que filtra por nombre de modelo o marca conforme escribes.
* **Carrito Lateral (*Drawer*) con Barra de Envío Gratis:**
  * Cálculo automático de subtotales y unidades.
  * Barra de progreso dinámica que calcula cuánto falta para alcanzar los **80,00€** y desbloquear el **Envío Express 24h Gratis**.

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico:** Estructura limpia y accesible en un único archivo portable.
* **Tailwind CSS (vía CDN):** Configuración personalizada del tema (`canas-black`, `canas-red`, `canas-neon`) y diseño 100% *Responsive* (Móvil, Tablet y Escritorio).
* **CSS3 Avanzado:** `@keyframes` para animaciones de flotación, *marquees* y transiciones `cubic-bezier`.
* **Vanilla JavaScript (ES6+):** Gestión de estado del carrito, filtrado de arrays, manipulación del DOM, eventos 3D y consumo asíncrono (`async/await` + `fetch`) de la API de imágenes.
* **Google Fonts:** Combinación tipográfica urbana:
  * `Syne` (Titulares agresivos de estilo streetwear).
  * `Space Grotesk` (Precios, tallas y etiquetas técnicas).
  * `Inter` (Cuerpo de texto legible).
* **Lucide Icons:** Iconografía vectorial moderna y ligera.
